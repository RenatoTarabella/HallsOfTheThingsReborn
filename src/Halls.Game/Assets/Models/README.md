# Models of the 3D view

The 3D view (F2 in the game) draws every cell of the map with a model from this
folder when `models.json` names one, otherwise with a box (walls, doors, stairs)
or with a card showing the character of 1983. So the game is complete without
any model, and models can be added one at a time.

The folder is copied next to `Halls.exe` (`bin/.../Assets/Models`): files can be
changed there and the game started again, without building.

## Format

Anything raylib loads: **glTF / GLB** (best: colours, textures, normals), OBJ (+MTL),
IQM, VOX (MagicaVoxel), M3D. From Blender: *File > Export > glTF 2.0*, format GLB,
*+Y Up* on.

## Conventions

- **1 cell = 1 unit**. The game places the model on the centre of its cell, with
  the base of the model on the floor (Y = 0): the bounding box is centred on X/Z and
  its bottom is put at 0, so the origin of the file does not matter.
- **Facing north = -Z** (up on the classic screen). The game turns the model
  clockwise seen from above: 90 = east, 180 = south, 270 = west. Use `rotationY`
  if the model was made looking elsewhere (e.g. `"rotationY": 180` for a model that
  faces +Z).
- `fit` (default `true`): the model is scaled so that its larger horizontal side
  is one cell, then by `scale`. For walls use `"fit": false` and model them at
  their true size, so that the pieces join.
- `offsetY`: raises the model (in cells).
- `tint`: multiplies the colours of the model by the Spectrum colour of the
  character (green walls, the seven colours of the rings, yellow treasure...).
  Handy to make one white model serve many codes.

## Keys

| key | what | turned by |
|---|---|---|
| `floor` | one cell of floor, drawn under everything | – |
| `wall_post` | wall cell with no neighbour | – |
| `wall_end` | wall ending here, the wall goes on **north** | the side it joins |
| `wall_straight` | wall going **north-south** | 0 or 90 |
| `wall_corner` | corner joining **north and east** | 0/90/180/270 |
| `wall_tee` | T joining **north, east and south** | 0/90/180/270 |
| `wall_cross` | cross | – |
| `door` | one of the 4 cells of a door, in a wall going **east-west** | 90 in walls going north-south |
| `forcefield` | one cell of the force field (doors of the sanctuary), drawn see-through last | – |
| `stairs_step`, `stairs_landing` | the stairs of the sanctuary (steps go down to the south) | – |
| `man` | the man: on the map he is 2 cells tall, here he stands at the joint of the two | where he looks |
| `thing_0`..`thing_7`, `thing` | the Things #D0-#D7 (all have the same rules, only the look changes) | where it goes (8 directions) |
| `treasure_0`..`treasure_3`, `treasure` | treasure, by the size of the heap (value 0-3, 4-7, 8-11, 12-15) | – |
| `potion_0`..`potion_3`, `potion` | potions, by the level in the bottle | – |
| `ring` | the seven rings (tinted with their colour), they turn | – |
| `key` | the golden key | – |
| `corpse_sword`, `corpse_arrow`, `corpse_burning`, `corpse` | the dead Things | – |
| `arrow`, `lightning`, `fireball` | projectiles | where they fly |
| `sword` | the sword while it swings | where the man looks |
| `arrow_bundle` | #D8-#DB, never generated by the game of 1983 | – |

`thing_6` does not exist: #D6 is the Thing **disguised as treasure** and is drawn
with `treasure_3` (or `treasure`), exactly as on the Spectrum where the two
characters are almost the same.

The first key found is used: `treasure_2` if it exists, else `treasure`, else the card.
